# Переезд на ФБС, пока горят склады

Конспект-лендинг по эфиру от 27 августа 2026 о переходе на схему ФБС на Ozon и Wildberries.

**Сайт:** https://sonya012408.github.io/fbs-pereezd/

## Что внутри

- **Коротко** — девять главных выводов эфира
- **Контекст** — что произошло с рынком после пожаров на складах
- **Цифры** — выкупаемость ФБО vs ФБС, скорость доставки по маршрутам, логика выбора склада отгрузки, соинвест и скрытые 5,5%
- **Как работает ФБС** — цикл заказа со схемой узких мест
- **Честный знак** — два пути работы с кизами, развилка возвратов, требования к 1 октября, проблема карточек 029
- **Фулфилмент** — топ проблем по опросу крупных селлеров
- **Стратегия** — дерево решений по размещению складов
- **Деньги** — тарифы хранения возвратов, утилизация, разбор страховки
- **Инструменты**, **чек-лист** на неделю и **словарь** терминов

Шесть авторских SVG-схем, тёмная тема, адаптив. Один файл `index.html`, без зависимостей.
